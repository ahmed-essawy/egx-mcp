## 5. Questions and answers (`ar-faq`)

Lead: إجابات قصيرة ومباشرة عن EGX MCP. كل إجابة مستقلة بذاتها.

1. **ما هو EGX MCP؟** EGX MCP خادم MCP مجاني يتيح لمساعدات الذكاء الاصطناعي الإجابة عن أسئلة أسهم البورصة المصرية ومؤشراتها وصناديقها ببيانات متأخرة. تربطه مرة واحدة بـ Claude أو ChatGPT أو Claude Code أو Cursor ثم تسأل بالعربية أو الإنجليزية.
2. **هل EGX MCP مجاني؟** نعم. EGX MCP مجاني وبلا إعلانات. يعمل على استضافة مجانية بحدود يومية، فإذا بلغ حدًا رُفضت الطلبات حتى اليوم التالي بدل أي رسوم.
3. **هل البيانات مباشرة؟** لا. بيانات الأسهم والمؤشرات متأخرة نحو 15 دقيقة أثناء الجلسة، وقيم وثائق الصناديق يومية، وكل إجابة تذكر وقت البيانات وأنها متأخرة.
4. **من أين تأتي البيانات؟** من مصادر عامة مجانية: موقع البورصة المصرية عندما يكون متاحًا، وTradingView، ومباشر، وiSagha لأسعار الذهب والفضة في مصر، ومواقع مديري الصناديق. المصادر غير رسمية، ولم تمنح البورصة المصرية إذنًا بإعادة نشر البيانات.
5. **ما مساعدات الذكاء الاصطناعي التي تعمل مع EGX MCP؟** Claude (على الويب وتطبيق سطح المكتب كموصل مخصص)، وChatGPT (تطبيقات وضع المطور)، وClaude Code، وCursor. ويمكن لأي عميل يدعم خوادم MCP البعيدة عبر Streamable HTTP مع OAuth أو ترويسة مفتاح أن يتصل.
6. **كيف أربط مساعدي؟** أضف عنوان الخادم {mcpUrl} في إعدادات الموصلات أو MCP في مساعدك وسجّل الدخول عبر Google، أو أرسل مفتاح API في الترويسة. لكل مساعد صفحة خطوات مرقمة على هذا الموقع.
7. **هل أحتاج إلى مفتاح API؟** لا في Claude وChatGPT لأنهما يسجلان الدخول عبر Google. يدعم Claude Code الطريقتين، ويستخدم Cursor مفتاحًا. تنشئ المفاتيح بعد تسجيل الدخول في {dashboardUrl}، ويظهر كل مفتاح مرة واحدة، ويمكن أن يكون لديك حتى {maxKeys} مفاتيح نشطة.
8. **هل يقدم EGX MCP نصائح استثمارية؟** لا. يعرض EGX MCP الحقائق ويحسبها مثل الأسعار والعوائد والنسب، ولا يقدم أبدًا نصيحة بالشراء أو البيع أو الاحتفاظ، ولا شيء مما يعيده نصيحة مالية.
9. **هل EGX MCP تابع للبورصة المصرية؟** لا. EGX MCP خدمة مستقلة، غير تابعة للبورصة المصرية ولا معتمدة أو مرعية منها.
10. **ماذا يمكنني أن أسأل؟** عن أسعار الأسهم والمؤشرات وأكبر المتحركين والقطاعات وتاريخ الأسعار وصناديق الاستثمار والتوزيعات والإجراءات المؤسسية والأرقام المالية وأسعار الذهب والفضة في مصر وسعر الدولار، إضافة إلى محفظتك ومستويات أسعارك. صفحة الأدوات تعرض كل أداة بمثال.
11. **كيف تبقى بياناتي خاصة؟** يتلقى EGX MCP طلبات الأدوات التي يرسلها مساعدك فقط، لا الأسئلة التي تكتبها، ولا يخزن مدخلات الأدوات. يحتفظ بمعرّف حساب Google وبريدك واسمك، وبصمات مفاتيح API، وعدد الطلبات اليومي لكل أداة، وأي مراكز ومستويات أسعار تحفظها ولا يراها غيرك. لا توجد أدوات تتبع ولا نصوص برمجية من أطراف ثالثة.
12. **كيف أحذف حسابي؟** سجّل الدخول في {dashboardUrl} واستخدم حذف الحساب. يحذف ذلك حسابك ومفاتيحك ومراكزك ومستويات أسعارك وسجلات استخدامك ويلغي اتصالات مساعدك.
13. **ما الفرق بين هذا وبين أن يبحث المساعد في الويب؟** بحث الويب يعيد صفحات قد تكون قديمة أو عن أسواق أخرى. أما EGX MCP فيعيد أرقام البورصة المصرية المخزنة مع وقت البيانات ومصدرها وعلامة التأخير في كل إجابة، فيستطيع مساعدك أن ينقل الأرقام مع عمرها.
14. **ما حدود الاستخدام؟** لكل حساب {userDailyCalls} طلب أدوات يوميًا و{perMinute} في الدقيقة، ويتشارك كل المستخدمين {globalDailyCalls} طلب يوميًا. تتجدد الحدود عند منتصف الليل بالتوقيت العالمي.
15. **هل يغطي صناديق الاستثمار والذهب وسعر الدولار؟** نعم. يغطي صناديق الاستثمار المصرية المدرجة على مباشر بقيم وثائق يومية، وأسعار الذهب والفضة للجرام في مصر، والجنيه الذهب، والذهب والفضة عالميًا بالدولار، وسعر الدولار مقابل الجنيه في السوق.
16. **ماذا يحدث عندما تبلغ الخدمة طاقتها؟** تُرفض الطلبات برسالة تذكر متى تحاول مجددًا، عادة بعد منتصف الليل بالتوقيت العالمي. لا توجد أي رسوم لأن الخدمة تعمل على استضافة مجانية فقط.
